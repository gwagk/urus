# DTMC URUS

**One Stop Endpoint Utility**

DTMC URUS is an endpoint lifecycle utility for Windows environments.

## Lifecycle

`RENAME → RESTART → INSTALL → VERIFY → HEALTHY`

Maintenance cycle:

`CHECK → DIAGNOSTIC → REPAIR → CLEAN → RECOVER`

## Status

This repository is under active development and testing.

Current target: Fresh Install validation on clean Windows VM.
